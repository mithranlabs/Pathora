# Pathora Synthetic Data Specification

**Product:** Pathora  
**Tagline:** *From alert noise to incident clarity.*  
**Status:** Pre-competition development fixtures.

> [!WARNING]
> All synthetic data generated by this module is for local architecture development, pipeline verification, and regression testing. None of these records represent official challenge data or real-world benchmark evaluations.

---

## 1. Generation Principles

- **Deterministic:** Generated with pseudo-random seed (default `42`). Calling the generator with the same seed produces byte-for-byte identical datasets.
- **Configurable Scale:**
  - `small` scale: ~41 alerts, 5 incident scenarios, fast local development (<1 sec).
  - `eval` scale: ~245 alerts, multi-service alert storms, stress test.
- **Strict Ground Truth Isolation:** Input files (`synthetic_*_alerts.json/csv/jsonl`) contain zero incident labels or root-cause attributes. Labels exist solely in `synthetic_*_ground_truth.json`.

---

## 2. Injected Real-World Scenarios

| Scenario ID | Scenario Name | Pattern & Description |
|---|---|---|
| `INC-001` | **Cascading Multi-Service Failure** | Root cause in `postgres-db` (connection saturation) cascades downstream to `checkout-svc` (500 errors) and `api-gateway` (504 timeout and circuit breaker trip). |
| `INC-002` | **Concurrent Independent Incident** | Firing in the exact same time window as INC-001, an independent Redis OOM and eviction storm occurs on `auth-cache` and `auth-svc`. |
| `INC-003` | **High-Volume Alert Storm** | An expired TLS certificate on `payment-gateway` triggers a burst of 15–60 payment handshake errors across `billing-svc` and `settlement-svc`. |
| `INC-004` | **Flapping Alerts** | An oscillating Kafka consumer lag on `inventory-svc` repeatedly transitions between `warning` and `critical` over 10 minutes. |
| `INC-005` | **Ambiguous Cyclic Deadlock** | `recommendation-svc` and `search-reranker` experience mutual gRPC RPC deadlock, alerting at the exact same second. True root cause is deliberately undetermined/ambiguous. |
| `DELAYED` | **Delayed / Out-of-Order Reporting** | A query warning from `checkout-svc` with an earlier timestamp is inserted out-of-order to test timestamp-aware replay vs file order. |
| `DIRTY` | **Dirty / Corrupted Telemetry** | Includes alerts with `service: null` and invalid timestamp strings (`INVALID_DATE`) to verify system resilience. |
| `NOISE` | **Unrelated Singleton Noise** | Background systemd and cron notices that belong to no incident. Must remain unclustered in an unattached lane. |

---

## 3. Synthetic Dependency Graph Flaws

The generated dependency graph in `synthetic_*_dependencies.json` contains realistic imperfections:
1. **Circular Call Dependency:** `recommendation-svc` $\leftrightarrow$ `search-reranker`.
2. **Stale Misleading Edge:** `inventory-svc` $\rightarrow$ `auth-cache` (an obsolete dependency that no longer exists in runtime calls).
